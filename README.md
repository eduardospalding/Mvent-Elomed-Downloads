# Downloads do Mvent Elomed

Aqui estão os arquivos destinados aos usuários do Mvent Elomed.

## Versão atual

**[Abrir a versão mais recente e escolher os arquivos para baixar](https://github.com/eduardospalding/Mvent-Elomed-Downloads/releases/latest)**

| Android | `Mvent_Elomed.apk` | Aplicativo de campo |
| Documentação | `Manual_Mvent_Analise.pdf` | Manual do programa para Windows |
| Documentação | `Manual_Mvent_App_Campo.pdf` | Manual do aplicativo de campo |
| Documentação | `Manual.do.usuario.-.Mvent.2026.V5.pdf` | Manual do equipamento |
| Documentação | Três PDFs com `Anexo` no nome | Anexos 1A, 1B e 1C do equipamento |

Para consultar a versão anterior, abra a página de [lançamentos](https://github.com/eduardospalding/Mvent-Elomed-Downloads/releases). Versões mais antigas são guardadas localmente pelo responsável pela publicação.
